# Notarizr App Overview

A simple guide to what Notarizr does and how the main parts work for **clients** and **notaries (agents)**.

---

## What is Notarizr?

Notarizr is a mobile app that connects people who need documents notarized with verified notaries.

Clients can book:

- **Mobile notary** — a notary comes to their location
- **Remote online notary (RON)** — a video session to notarize documents online

Notaries can:

- Set when and where they are available
- Accept or decline booking requests
- Complete the notarization (in person or on a video call)
- Get paid through the app

---

## Who uses the app?

| Role | Meaning |
|------|---------|
| **Client** | Someone who needs a notary |
| **Notary / Agent** | A verified notary who provides the service |

One account can switch between **Client** and **Notary** in Settings.

---

## How the app starts

1. App opens on the splash screen
2. If the user is logged in → go to Home
3. If not → Login or Sign up
4. New users may see a short onboarding first

### Sign up (simple path)

1. Choose role: Client or Notary
2. Enter personal details
3. Verify phone with OTP
4. Add a profile picture
5. If Notary → upload ID / certificate for verification
6. Account is ready (notaries may wait for approval)

### Login

1. Enter phone number
2. Enter OTP
3. Enter the app

---

## Main service types

### 1. Mobile notary

- Client picks a date, time, and address
- App finds an available notary nearby
- Notary travels to the client
- Documents can be notarized in person

### 2. Remote online notary (RON)

- Client uploads documents
- Client picks a date and time
- Notary and client meet on a video call
- Documents can be signed and stamped during the session

Document categories notaries can support include Legal, Estate, Medical, and Business.

---

# Client side

## Main tabs

- **Home** — start a booking
- **Bookings** — see all booking requests and status
- **Messages** — chat with a notary
- **Profile** — account, addresses, settings

## How a client books (main flow)

1. Open **Home**
2. Choose **Mobile notary** or **Remote online**
3. Go through the booking steps:
   - Step 1: date / time (and address for mobile)
   - Step 2: upload documents, add notes, choose print options if needed
   - Step 3: review price and confirm
4. App matches an available notary and creates the booking
5. Client waits for the notary to accept
6. Booking details show status, chat, payment, and next actions

## After the booking is accepted

### For mobile notary

- Client can see booking details and location
- Notary comes to the address
- Client can chat with the notary
- Payment is handled through the app when required

### For remote online notary

- Client prepares documents and ID if needed
- Client joins a waiting room
- Client joins the video session
- Signing and stamping happen during the call
- Finished documents can be downloaded later

## Other client modules

| Module | What it does |
|--------|--------------|
| **Addresses** | Save and manage booking locations |
| **Payments / cards** | Add a card and pay for services |
| **Chat** | Message the assigned notary |
| **Notifications** | Get updates when a booking is accepted, started, or completed |
| **Settings** | Preferences, delete account, switch to Notary mode |
| **Support** | FAQ, privacy policy, terms |

## Client booking statuses (simple view)

- **Pending** — waiting for a notary to accept
- **Accepted / Ongoing** — notary is working on it
- **Completed** — notarization is done
- **Paid** — payment finished
- **Cancelled / Rejected** — booking did not continue

# Notary (agent) side

## Main tabs

- **Home** — earnings summary, setup shortcuts, new requests
- **Bookings** — manage active and upcoming jobs
- **Completed** — past finished jobs
- **Messages** — chat with clients
- **Profile** — account, verification, settings

## First-time notary setup

1. Sign up as Notary
2. Upload photo ID and notary certificate
3. Wait for account review / approval
4. Set up payouts (so earnings can be sent)
5. Turn on Mobile and/or Remote availability
6. Choose which document categories they serve

## How a notary gets work

1. Client creates a booking
2. Request appears on notary Home / New Requests
3. Notary opens the client/booking details
4. Notary accepts or declines
5. If accepted, the job moves into their bookings

## Mobile notary job flow

1. Accept the request
2. Open map / directions to the client location
3. Arrive and start the job
4. Review documents and complete notarization
5. Mark the booking complete
6. Payment / earnings update in the app

## Remote online notary job flow

1. Accept the request
2. Invite or wait for the client session
3. Join the waiting room / video call
4. Review documents on screen
5. Apply stamp / signature during the session
6. Finish the call and complete the booking

## Other notary modules

| Module | What it does |
|--------|--------------|
| **Availability** | Set when and where they can take jobs |
| **Service preferences** | Choose Mobile / RON and document categories |
| **Verification** | Upload and manage credentials |
| **Stamp & signature** | Save stamp and signature for online sessions |
| **Payouts / transactions** | Track earnings and payout setup |
| **Chat** | Message clients about bookings |
| **Notifications** | Get alerts for new requests and booking updates |

# Shared features (both sides)

These parts are used by both clients and notaries:

- **Chat** — talk about a booking
- **Calls** — voice or video for online notarization
- **Notifications** — booking and session updates
- **Profile** — name, photo, personal details
- **Settings** — preferences and account actions
- **Role switch** — change between Client and Notary in Settings
- **Documents** — upload, view, and download files tied to a booking

---

# Simple end-to-end picture

## Client path

`Sign up / Login → Home → Choose service → Booking steps → Confirm → Wait for accept → Pay if needed → Meet in person or join video → Get notarized documents`

## Notary path

`Sign up / Verify → Set payouts → Set availability → Receive request → Accept → Travel or join video → Complete notarization → Get paid`

---

# Settings: switching roles

In **Settings**, the user can switch between:

- **Client mode** — book notary services and manage booking preferences
- **Notary mode** — receive jobs and manage availability

If someone switches to Notary for the first time, the app may ask them to complete verification first.

# Summary

Notarizr has two clear experiences in one app:

1. **Clients** book mobile or online notarization, upload documents, chat, pay, and finish the session.
2. **Notaries** set availability, accept jobs, complete in-person or video notarization, and receive payouts.

Everything else (chat, calls, notifications, profile, and settings) supports those two main journeys.
